# Tools

Every APERO tool, user-facing and developer-only, at a glance. Tools are run directly rather than as part of a processing sequence - use this table to find the one you need, then click through for its full usage.

| Name | Type | Instruments | Description |
| --- | --- | --- | --- |
| [apero_ari](/docs/apero/user_tools/ari) | User tool | All | Run the ARI (APERO reduction interface). |
| [apero_astrometrics](/docs/apero/user_tools/astrom) | User tool | All | Run this recipe to check, find and/or add targets to the online astrometric database. |
| [apero_explorer](/docs/apero/user_tools/explo) | User tool | All | Opens a GUI browser to help one navigate the raw, working and reduced directories. |
| [apero_get](/docs/apero/user_tools/get) | User tool | All | Use database to search and copy any files quickly. |
| [apero_go](/docs/apero/user_tools/go) | User tool | All | Use this tool to find current paths set by current profile. |
| [apero_listing](/docs/apero/user_tools/list) | User tool | All | Rebuilds index files. |
| [apero_precheck](/docs/apero/user_tools/precheck) | User tool | All | PRECHECK_DESCRIPTION. |
| [apero_processing](/docs/apero/user_tools/proc) | User tool | All | Process a night or a set of nights or all nights given some options and a run file. |
| [apero_queue](/docs/apero/user_tools/queue) | User tool | All | The APERO queue management tool - run, batch, monitor and reset the processing queue (created by apero_processing in queue mode). |
| [apero_reject](/docs/apero/user_tools/reject) | User tool | All | Add a object or file to the object or file reject list online. |
| [apero_remove](/docs/apero/user_tools/remove) | User tool | All | The APERO file/directory remove tool. |
| [apero_reset](/docs/apero/user_tools/reset) | User tool | All | Resets the DRS raw/tmp/db/reduced files based on user input. |
| [apero_stats](/docs/apero/user_tools/stat) | User tool | All | Performs a log analysis on the log.fits files generated by recipes. |
| [apero_trigger](/docs/apero/user_tools/trigger) | User tool | All | Basic (brute force) trigger for APERO. |
| [apero_validate](/docs/apero/user_tools/valid) | User tool | All | Runs the DRS validate script (If this script runs the APERO frame work has been installed successfully). |
| [apero_visu](/docs/apero/user_tools/visu) | User tool | All | APERO visualizer. |
| [apero_database](/docs/apero/user_tools/apero_database) | User tool | All | This script has no DrsRecipe metadata yet. |
| [apero_database_kill](/docs/apero/user_tools/apero_database_kill) | User tool | All | Stops APERO database process entries that exceed the configured 60-minute timeout. |
| [apero_changelog](/docs/apero/dev_tools/clog) | Developer tool | All | Produces a nicely formatted change log (using git). |
| [apero_dependencies](/docs/apero/dev_tools/depend) | Developer tool | All | Run a dependency check on the DRS (Will display all modules required and some stats). |
| [apero_documentation](/docs/apero/dev_tools/doc) | Developer tool | All | Re-make the apero documentation. |
| [apero_langdb](/docs/apero/dev_tools/lang) | Developer tool | All | Language database tools. |
| [apero_update_run_config](/docs/apero/dev_tools/run_ini) | Developer tool | All | Create default run.ini files for APERO instrument(s). |
| [apero_assets](/docs/apero/dev_tools/apero_assets) | Developer tool | All | Checks, updates, and synchronizes APERO data-asset checksums. |
| [apero_constants](/docs/apero/dev_tools/apero_constants) | Developer tool | All | Generates or cleans constant modules and creates the constants glossary. |
| [apero_optimize](/docs/apero/dev_tools/apero_optimize) | Developer tool | All | Checks Python source files for missing docstrings and unused functions. |

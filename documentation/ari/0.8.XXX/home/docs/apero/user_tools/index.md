# User tools

Tools you run yourself to set up, inspect, query and manage an APERO reduction.

| Name | Description |
| --- | --- |
| [apero_ari](/docs/apero/user_tools/ari) | Run the ARI (APERO reduction interface). |
| [apero_astrometrics](/docs/apero/user_tools/astrom) | Run this recipe to check, find and/or add targets to the online astrometric database. |
| [apero_explorer](/docs/apero/user_tools/explo) | Opens a GUI browser to help one navigate the raw, working and reduced directories. |
| [apero_get](/docs/apero/user_tools/get) | Use database to search and copy any files quickly. |
| [apero_go](/docs/apero/user_tools/go) | Use this tool to find current paths set by current profile. |
| [apero_listing](/docs/apero/user_tools/list) | Rebuilds index files. |
| [apero_precheck](/docs/apero/user_tools/precheck) | PRECHECK_DESCRIPTION. |
| [apero_processing](/docs/apero/user_tools/proc) | Process a night or a set of nights or all nights given some options and a run file. |
| [apero_queue](/docs/apero/user_tools/queue) | The APERO queue management tool - run, batch, monitor and reset the processing queue (created by apero_processing in queue mode). |
| [apero_reject](/docs/apero/user_tools/reject) | Add a object or file to the object or file reject list online. |
| [apero_remove](/docs/apero/user_tools/remove) | The APERO file/directory remove tool. |
| [apero_reset](/docs/apero/user_tools/reset) | Resets the DRS raw/tmp/db/reduced files based on user input. |
| [apero_stats](/docs/apero/user_tools/stat) | Performs a log analysis on the log.fits files generated by recipes. |
| [apero_trigger](/docs/apero/user_tools/trigger) | Basic (brute force) trigger for APERO. |
| [apero_validate](/docs/apero/user_tools/valid) | Runs the DRS validate script (If this script runs the APERO frame work has been installed successfully). |
| [apero_visu](/docs/apero/user_tools/visu) | APERO visualizer. |
| [apero_database](/docs/apero/user_tools/apero_database) | This script has no DrsRecipe metadata yet. |
| [apero_database_kill](/docs/apero/user_tools/apero_database_kill) | Stops APERO database process entries that exceed the configured 60-minute timeout. |

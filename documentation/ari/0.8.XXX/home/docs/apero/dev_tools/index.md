# Developer tools

Tools used to maintain APERO itself. Most users will never need these.

| Name | Description |
| --- | --- |
| [apero_changelog](/docs/apero/dev_tools/clog) | Produces a nicely formatted change log (using git). |
| [apero_database](/docs/apero/dev_tools/dbmgr) | APERO database manager functionality. |
| [apero_dependencies](/docs/apero/dev_tools/depend) | Run a dependency check on the DRS (Will display all modules required and some stats). |
| [apero_documentation](/docs/apero/dev_tools/doc) | Re-make the apero documentation. |
| [apero_langdb](/docs/apero/dev_tools/lang) | Language database tools. |
| [apero_update_run_config](/docs/apero/dev_tools/run_ini) | Create default run.ini files for APERO instrument(s). |
| [apero_assets](/docs/apero/dev_tools/apero_assets) | Checks, updates, and synchronizes APERO data-asset checksums. |
| [apero_constants](/docs/apero/dev_tools/apero_constants) | Generates or cleans constant modules and creates the constants glossary. |
| [apero_optimize](/docs/apero/dev_tools/apero_optimize) | Checks Python source files for missing docstrings and unused functions. |

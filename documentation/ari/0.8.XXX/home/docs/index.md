# APERO documentation

APERO reduces SPIRou and NIRPS observations. This documentation supports
several tasks: learning the pipeline, finding a recipe or tool, installing and
operating a reduction, and developing or troubleshooting APERO. Use the
version selector to choose documentation that matches your code release.

| Section | Use it to |
| --- | --- |
| [APERO reference](apero/) | Understand how reductions are run, compare recipes across instruments, and look up sequences, tools, and file definitions. |
| [Installation](install) | Set up APERO for routine use or development. |
| [ARI API](api) | Access reduction data programmatically from Python. |
| [Developer documentation](developer/) | Learn APERO architecture and make changes to recipes, constants, keywords, plots, and other code. |
| [Reference guides](reference/) | Find environment, database, and operational command references. |
| [Core algorithms](algorithms/) | Follow the scientific methods and implementation details behind reduction steps. |
| [Monitoring documentation](monitor) | Interpret checks and carry out monitor workflows. |
| [Known errors](known_errors) | Look up recurring failures and recommended operator actions. |
| [Glossary](glossary) | Find concise definitions of APERO and astronomy terms used here. |

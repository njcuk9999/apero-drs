# APERO reference guides

Practical reference material for operating and developing APERO.

Choose a guide by the task at hand. Installation instructions are release-
specific. The database page is a cautious query reference; use APERO's own
database tools rather than direct SQL for routine production changes.

| Guide | Scope |
| --- | --- |
| [Developer environments](developer_environments) | Conda, venv, Git, pip, editable source installs, and local profile setup. |
| [Alliance installation](alliance_install) | HPC installation workflow and cluster-specific cautions. |
| [MySQL commands](mysql) | Read-only schema inspection and safe SQL patterns for administrators. |

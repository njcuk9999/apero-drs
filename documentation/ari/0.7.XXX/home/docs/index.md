# APERO v0.7 documentation

APERO v0.7 uses an `ini` run file to configure batch processing with
`apero_processing`. It predates the v0.8 queue workflow and has different
recipe interfaces, file definitions, and installation requirements.

The v0.7 reference pages must be generated from a matching v0.7 checkout;
using v0.8 definitions would describe the wrong pipeline. Until that reference
set is generated, use the preserved install guidance and switch to v0.8 for
the current generated recipe and instrument catalog.

| Destination | What it contains |
| --- | --- |
| [v0.7 installation](install) | Setup instructions for v0.7 releases, including the older Python version used by early v0.7. |
| [v0.8 documentation](/docs/?v=0.8.XXX) | Current generated v0.8 recipes, tools, sequences, and file definitions. |

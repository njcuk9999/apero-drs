# Documentation

The Documentation area serves Markdown from the repository documentation
tree. APERO command pages can be generated from live recipe definitions;
operator and RI guides are authored pages.

## Current capabilities

- Browse the documentation tree and use its search box.
- Switch documented APERO versions where a version is available.
- Open generated recipe, sequence, tool, and file-definition references.
- Open ARI-specific operator guides such as this one.
- Edit documentation only with the appropriate documentation permission.

## Adding content

Version-specific APERO documentation belongs below the matching
`documentation/ari/<version>/home/docs/` directory. RI content that applies to
all supported versions belongs below `documentation/ari/all/home/docs/`.

!!! tip
    Keep detailed operator workflows in authored pages. Do not put them in
    generated APERO reference directories because generation rebuilds those
    directories.

Detailed editing and publication instructions will be expanded here.

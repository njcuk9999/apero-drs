# Pins

Pins provide a personal shortlist of ARI resources. A pin is a navigation
shortcut, not a copy of the pinned resource, and it does not override
permissions.

Expected use cases include returning to an object, profile, issue, schedule,
or frequently used administrative page.

Detailed pin organization and sharing behavior will be added here.

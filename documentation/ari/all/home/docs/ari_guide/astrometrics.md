# Astrometrics

Astrometrics resolves target names and coordinates, stores catalogue results,
and supports review of aliases and uncertain matches.

The current implementation provides catalogue lookup, target resolution,
review workflows, and scheduled maintenance. It may contact configured
external catalogue services and stores resulting APERO RI assets locally.

Detailed catalogue, confidence, review, and submission workflows will be
added here.

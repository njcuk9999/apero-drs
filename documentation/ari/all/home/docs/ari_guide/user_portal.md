# User Portal

The User Portal contains personal account and collaboration features.
Depending on permissions, it may include:

- API access and tokens;
- downloads and shared links;
- user messaging;
- profile and page preferences;
- account and password settings;
- user or group discovery.

An API token grants only the authenticated user's permitted resources. Treat
tokens as secrets and revoke any token that is exposed.

Detailed account, API, download, and messaging workflows will be added here.

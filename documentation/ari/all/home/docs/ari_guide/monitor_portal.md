# Monitor Portal

The Monitor Portal is for operational monitoring rather than product
exploration. Access is controlled by monitor and instrument permissions.

## Main areas

- APERO checks and check history;
- known and unresolved issues;
- schedules and observation timelines;
- APERO queue dashboards;
- profile health and data availability.

Monitor pages need up-to-date profile data, background tasks, and the remote
queue tunnel where queue monitoring is enabled.

See [Monitoring documentation](../monitor) for check-specific guides. More
ARI Monitor Portal workflow detail will be added here.

# Search

ARI Search has three distinct jobs:

- object and observation search;
- APERO property search using indexed FITS/header and spectrum fields;
- documentation and permitted site-page search.

Results are permission-filtered. A search result never grants access to a
profile the user could not otherwise open.

Property choices come from the search index maintained by an asynchronous
task. Detailed examples and index troubleshooting will be added here.

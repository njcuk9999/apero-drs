# How to figure out when observations should happen

Use this timeline to decide whether a missing-data alert is normal delay or
needs escalation.

| Activity | UTC |
| --- | --- |
| HELIOS observations | 09:00-12:00 and 14:00-19:00 |
| Daily-Calibrations Full-Set start | 12:00 |
| Daily-Calibrations Full-Set end | 14:00 |
| Afternoon-Calibrations start | 20:00-21:00 |
| Afternoon-Calibrations end | 21:00-22:00 |
| Telluric stars | 21:00-22:00 |
| Night observations | 22:00-09:00 (next day) |

Notes:

- In normal operation, allow for expected transfer delays.
- If checks are run for yesterday, data should normally be available.
- Use this timing with the ESO archive view before sending alerts.

# How to find whether there should be science data

Absence of local science files can mean:

- no science was observed
- science was observed but not transferred
- science exists but is not accessible to our program rights

Workflow:

1. Check expected timing in observation timeline.
2. Check observer log and comments for the night.
3. Search ESO special archive (with PI/CoI access when required).
4. For HE vs HA split, enable `Orig Name` in data product columns.
5. If needed, cross-check ESO schedule (`NIRPS`, `3P6`) and program IDs.

Good reasons for no science include bad weather, technical issues, or non-GTO
nights.

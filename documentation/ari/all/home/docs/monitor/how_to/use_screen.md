# How to use screen on UdeM machines

Common sessions:

- `nirps_he_online`
- `nirps_ha_online`
- `nirps_he_offline`
- `nirps_ha_offline`

Useful commands:

```bash
screen -list
screen -r {screen_name}
screen -R {screen_name}
screen -x {screen_name}
```

Shortcuts:

- detach without stopping: `Ctrl+A` then `D`
- terminate shell: `Ctrl+D`
- scroll mode: `Ctrl+A` then `Esc`

Astrometrics

This page gives access to the APERO astrometric database. Note that only objects already added to our database are resolvable by coordinates here; for any other target, use the "Resolve online" button (under the Resolve target tab) which will query SIMBAD, Vizier and other public services.

Rejected and unknown targets: any object name that has been added to the rejection list (see the "Rejected object names" tab) is excluded from the data portal. Targets with no astrometric entry — and any observation whose object name resolves to a rejected name — fall back to the values found in the FITS header (RA / Dec / PMRA / PMDE / OBJECT etc.) at reduction time rather than to a curated entry.

DB SSH Tunnel Definitions

Quick setup checklist: 1) Fill definition name, SSH host alias, remote database host, remote database port, and local forward port. 2) Enter test username/password/database name. 3) Click Test Connection before saving whenever possible. 4) Save tunnel definition. 5) Click Start / Verify Tunnel (or Interactive Auth if prompted). 6) Re-run Test Connection to confirm.
Tip: Keep local forward ports unique per definition (for example 3307, 3308, ...).
Note: Multiple DB SSH tunnels can be active at the same time.

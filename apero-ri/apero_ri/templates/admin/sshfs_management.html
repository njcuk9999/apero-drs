Terminology

Client: this machine (where APERO RI runs).
Server: the remote machine you want to access.
SSHFS mounts a server directory so it appears as a local folder on the client.

Step-by-step Guide

  1. On the client, generate an SSH key pair (Linux/macOS): 
    ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_ari_sshfs -N ""
cat ~/.ssh/id_ed25519_ari_sshfs.pub
  2. On the server, add the public key to authorized_keys: 
    mkdir -p ~/.ssh
chmod 700 ~/.ssh
echo "ssh-ed25519 AAAA..." >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
  3. In the SSH Keys tab, add your private key so this app can authenticate to the server. 
    cat ~/.ssh/id_ed25519_ari_sshfs
  4. In Setup, choose either direct host/user or an SSH config host alias, then click Test SSH connection. This checks authentication and verifies the remote path is reachable.
  5. After test passes, click Add Mount. Then use Mount Status to mount/unmount and monitor health.

Server-side Checklist

  • SSH daemon is running on the server.
  • The target directory exists and is readable by the SSH user.
  • The server allows SSH access from this client.
  • Permissions are correct on ~/.ssh and ~/.ssh/authorized_keys.

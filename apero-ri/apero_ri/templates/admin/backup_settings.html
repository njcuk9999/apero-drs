Credentials & connection

  1. Create or select your Google Cloud project in console.cloud.google.com.
  2. Open Google Auth Platform (or OAuth consent screen) → Audience and add your Google account under Test users while the app is in testing.
  3. Go to APIs & Services → Credentials.
  4. Create an OAuth 2.0 Client ID (Application type: Web application).
  5. Under Authorized redirect URIs, add the exact callback URL shown below and save.
    Note: Google can take a few minutes (and sometimes up to a few hours) to propagate new redirect URIs.
  6. Click Download JSON, then upload it using the Upload JSON button below.
  7. Enter the Google Drive folder ID, then click Connect Google account.

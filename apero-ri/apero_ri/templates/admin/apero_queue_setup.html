APERO Queue Definition

Quick setup checklist: 1) Establish the SSH master and open its interactive shell, then start the dashboard inside that same shell. This pins the queue to the login node used by the master. 2) Fill in that SSH config host, the remote port and a free local port. 3) Link the queue to an APERO profile - monitors who can access that profile will see the queue. 4) Save, then click Start / Verify Tunnel (or Interactive Auth for password / Duo prompts).
Equivalent command: ssh -L LOCAL_PORT:localhost:REMOTE_PORT SSH_HOST

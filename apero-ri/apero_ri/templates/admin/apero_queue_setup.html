APERO Queue Definition

Quick setup checklist: 1) On the cluster start the dashboard, e.g. apero_queue.py gui --port 8090 (it listens on localhost only). 2) Fill in the SSH config host of the same login node (use a node-specific alias, not a round-robin one), the remote port and a free local port. 3) Link the queue to an APERO profile - monitors who can access that profile will see the queue. 4) Save, then click Start / Verify Tunnel (or Interactive Auth for password / Duo prompts).
Equivalent command: ssh -L LOCAL_PORT:localhost:REMOTE_PORT SSH_HOST

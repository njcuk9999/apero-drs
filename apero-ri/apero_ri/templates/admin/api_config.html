Server API Config

Configure the server-side API settings used by the checker host. These values are read from the ARI data directory on the machine that runs the APERO checks.

Active location

Resolved ARI data directory: {{ resolved_data_dir }}
Expected config file: {{ api_config_path }}
Status: {{ api_config_status }}

What to set

  1. server: the base URL of this ARI instance, for example https://your-ari-host.
  2. token: the API token generated from the user portal API Access page.

On the server machine

Run these commands on the same machine that hosts the APERO checks. The checker process reads this file from the ARI data directory shown above. 

mkdir -p "{{ resolved_data_dir }}"
cat > "{{ api_config_path }}" <<'EOF'
{
  "server": "https://your-ari-host",
  "token": "paste-your-api-token-here"
}
EOF
chmod 600 "{{ api_config_path }}"

If your checker process uses a different ARI data directory, set ARI_DIR before running it so the same path is used.

Where to get the token

Open the user portal API Access page on the ARI instance and generate or copy a token there. Then paste that token into the file above.

After saving the file, re-run the ASTROM check so the checker can pick up the new settings.

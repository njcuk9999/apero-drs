What is APERO RI?

The APERO Reduction Interface (APERO RI) is a web-based front-end for the A PipelinE to Reduce Observations (APERO) data reduction system. It provides tools for browsing observations, inspecting reduced data products, viewing quality-control plots, and managing reduction tasks for high-resolution spectrographs such as SPIRou, NIRPS, and others.

How to use this table Info
  1. Filter columns: Click on the input fields below each column header to filter by text or values. Use these to find specific objects or narrow down your results.
  2. Show or hide columns: Click the Columns button to customize which columns are visible in the table.
  3. Navigate to object page: Click on any object name to view detailed information about that object, including its spectrum data and file browser.
  4. Add files to download basket: On the object page, select the File Browser tab, then use the basket icons to add files to your download basket.
Notes
  • If a target is missing, review your current permissions in User Portal / Data Access.
  • File counts show N (M) where N is the number of files accessible to you and M is the total across all run IDs.

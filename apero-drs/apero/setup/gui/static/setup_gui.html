Create a new APERO profile with apero_setup.py. Work through the sections (hover over a field for its description), then press Validate and save. Setup then writes the profile files to DRS_UCONFIG, creates the directories, downloads the assets and (optionally) cleans the database; any remaining questions are answered in the console below.

Edit the files apero_setup.py wrote to a profile's DRS_UCONFIG directory as a form (each constant links to its Docs entry) or as raw text, review the changes side by side and save (a backup is kept). + Add parameters adds any parameter not in the file yet and ✕ removes one (back to its default). Then re-run setup to apply the new paths / database / plot settings.

Setup reads the profile name, instrument,
language, data paths and plot mode from install.yaml /
user_config.yaml, the database settings from
database.yaml and the clean start choices from
install.yaml SETUP_ARGUMENTS, then writes every
file again, creates missing directories and (if CLEAN_START)
cleans the profile.


Note: the user
yamls are written again from the APERO defaults plus the setup values -
other values you changed in user_config.yaml /
user_constants.yaml / user_keywords.yaml are
reset. The files are kept before the re-run and Show what changed
compares them afterwards (each saved file also has a backup).

Reset (apero_reset.py)


Removes the files APERO made for this profile and
resets the matching databases. Everything resets every part below:
the assets directory is rebuilt from the APERO reset assets (downloading
the assets first if they are missing or out of date) and every database
is reset. Choose one part to reset only that part. Raw data is never
reset.
